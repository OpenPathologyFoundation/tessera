Quick Start Guide

Quick Start

  1. Open the app in Chrome, Firefox, or Edge.
  2. Enter case/accession number (optional — type or scan barcode) and pick specimen type, then press Enter or click Start Count.
  3. Press keys to count — the same 14 keys are used for both BM and PB (see table below). The upper row holds precursor cells, the lower row holds mature cells.
  4. Click “Count Done” when you reach the target (500 BM / 200 PB — advisory, not enforced), then copy the formatted output into your LIS/EMR.
  5. Continue Counting — if you need more cells after reviewing results, click “Continue Counting” to resume where you left off.

Tips

  • Undo a miscount — hold Shift + the key you want to correct (decrements by 1).
  • Morphology comments — expand the comments field during counting to note findings (500 char limit). Typing in the field won't trigger counts.
  • Theme toggle — press Ctrl+Shift+L (or Cmd+Shift+L on Mac) to switch between dark and light mode.
  • Session history — completed counts are listed at the bottom of the page for the current browser session. Export to CSV or JSON for a local record.
  • Output templates — after completing a count, switch between institutional output formats using the tabs (e.g., Yale SOM, MGH, Precipio DX).
  • Continue Counting — after reviewing results, click “Continue Counting” to resume from where you left off and add more cells.
  • M:E Ratio — displayed live during BM counting (myeloid / erythroid). Not shown for PB.
  • Methods & Limitations — read this for how percentages, the M:E ratio and confidence intervals are calculated, which standards they follow, and what a manual differential count can and cannot establish.
  • Preset Profiles — open the preset catalogue from the case-entry screen to switch between built-in layouts (full 14-part consensus, harmonized 9-part, legacy 9-part, minimal 5-part, body fluid, frequency-ergonomic, right-hand). Loading a preset replaces the active configuration and starts a clean case.
  • Export/Import Config — use the links on the case-entry screen to export your current configuration as a JSON file, or import one from a colleague to share key layouts and templates. An imported profile is validated before it is applied; one that cannot be counted with is rejected with the reason shown.
  • Configuration Editor — open the Configuration Editor to visually customize cell layout, key assignments, and output templates. Click a cell card and press a key to assign it. Use “Auto-Assign: Left Hand” or “Auto-Assign: Right Hand” to quickly map all cells to an ergonomic zone.
  • Left-handed operators — use the right-hand preset or auto-assign right-hand keys in the editor, so keys cluster on HJKL;/NM,./ while your left hand operates the microscope.

Data & Privacy

All data stays in your browser. Nothing is transmitted to any server. Session history is cleared when you close the tab.
